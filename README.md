
# 🎬 Clone da Netflix

### Interface Front-End com HTML, CSS e JavaScript

O **Clone da Netflix** é um projeto Front-End desenvolvido com HTML, CSS e JavaScript, inspirado na interface da plataforma de streaming Netflix, com foco em organização visual, interatividade e responsividade.

## 🎯 Problema e Solução

**Problema:** desenvolver interfaces semelhantes às de plataformas digitais exige organização de conteúdo, posicionamento de elementos e adaptação para diferentes dispositivos.

**Solução:** uma interface inspirada na Netflix que reproduz elementos visuais de uma plataforma de streaming, utilizando tecnologias fundamentais do Front-End.

## 🚀 Funcionalidades

- Interface inspirada na Netflix
- Organização visual de filmes e conteúdos
- Layout moderno e responsivo
- Interações com JavaScript
- Adaptação para diferentes tamanhos de tela

## 🛠️ Tecnologias

**Front-End**
- HTML5
- CSS3
- JavaScript
- DOM

## 💡 Desafio Técnico

O principal desafio foi reproduzir uma interface inspirada em uma plataforma real, trabalhando posicionamento de elementos, estilização com CSS, interatividade e responsividade.
